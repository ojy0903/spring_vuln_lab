# Spring Vuln Lab — 취약점 실습 및 패치

> ⚠️ **경고: 이 저장소는 보안 교육용으로 의도적으로 취약하게 작성된 코드를 포함합니다.**
> 실제 서비스 환경에 배포용이 아닙니다. 모든 공격 실습은 로컬 환경 또는 본인 소유의
> 연습용 타겟에서만 진행합니다.

OWASP 주요 웹 취약점을 **의도적으로 심은 취약 버전**과 **안전하게 패치한 버전**을
나란히 구현하고, 직접 공격을 재현하면서 원인과 대응을 정리하는
학습용 프로젝트입니다. 백엔드(Spring Boot) 관점에서 "왜 취약한가 → 어떻게
고치는가"를 코드 레벨로 비교하는 데 초점을 둡니다.
